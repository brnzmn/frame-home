# frame-home

A tvOS-style launcher and a global frame look for a Samsung Frame Pro (2025, Tizen 9), installed through Samsung's Developer Mode. No firmware is modified.

- `docs/plan.md`: the approved plan and its phases.
- `docs/decisions.md`: what was decided and why.
- `docs/RUNBOOK.md`: how to deploy to the TV and use the frame tools.
- `probe/`: the test app that records what the TV allows.
- `tools/`: finding the TV, deploying, inspecting, and the frame-look tools.

Status: Phase 0 (proof on the TV). Nothing has been verified on the TV yet.
